# 2025年北京市劳动模范先进事例（手机端）

这是一个无需安装依赖的静态手机网页。上传整个文件夹到任一静态网站空间后，访问 `index.html` 即可使用。

## 上线与二维码

1. 将本文件夹上传到您的网站目录，例如 `https://您的域名.cn/2025-labor-model/`。
2. 用该完整网址生成二维码；二维码必须指向公网网址，不能指向本机文件或 `localhost`。
3. 在微信、支付宝及系统相机中各测试一次扫码效果。

如您提供已可访问的网址，我可以据此生成最终 PNG/SVG 二维码。

## 内容维护

- 名单、单位与职务整理自北京市总工会 2025 年 4 月 28 日发布的《全国劳动模范》：
  <https://www.bjzgh.org/zt/2025ldmf/grb/qgldmf/202504/20250428/j_2025042820154900017458425698081934.html>
- `data.js` 中每一项可增加 `photo` 字段，例如：`photo:'images/徐树永.jpg'`。请仅使用已取得肖像授权的官方照片。
- 当前“事迹简介”是根据公开岗位信息生成的简要说明，并非逐人官方事迹全文。请在取得宣传部门审核的个人事迹材料后，改写该字段为经审核版本。
