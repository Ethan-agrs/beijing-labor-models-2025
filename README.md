# 2025年北京市劳动模范先进事例（手机端）

这是一个无需安装依赖的静态手机网页。上传整个文件夹到任一静态网站空间后，访问 `index.html` 即可使用。

## 目录结构

```
beijing-labor-models-2025/
├── index.html      # 页面入口
├── styles.css      # 样式（含圆形头像、详情大图、全屏灯箱）
├── data.js         # 51 名劳模名单、单位职务、分类与照片路径
├── app.js          # 分类导航、卡片渲染、详情大图与原图灯箱交互
└── images/          # 51 张本人肖像，文件名 = 姓名.jpg
```

## 照片展示方式

- 列表卡片左侧为圆形头像（`images/姓名.jpg`）。
- 点开详情后，正文上方展示本人肖像大图；点击大图或头像可弹出全屏灯箱，查看原图大图。
- 灯箱支持点击遮罩、右上角关闭按钮或 `Esc` 键关闭。

## 上线与二维码

1. 将本文件夹上传到您的网站目录，例如 `https://您的域名.cn/2025-labor-model/`。
2. 用该完整网址生成二维码；二维码必须指向公网网址，不能指向本机文件或 `localhost`。
3. 在微信、支付宝及系统相机中各测试一次扫码效果。

如您提供已可访问的网址，我可以据此生成最终 PNG/SVG 二维码。

## 内容维护

- 名单、单位与职务整理自北京市总工会 2025 年 4 月 28 日发布的《全国劳动模范》：
  https://www.bjzgh.org/zt/2025ldmf/grb/qgldmf/202504/20250428/j_2025042820154900017458425698081934.html
- `data.js` 中每一项的 `photo` 字段指向本地照片，例如：`photo:'images/徐树永.jpg'`。替换照片时保持 `images/姓名.jpg` 同名即可。
- 请仅使用已取得肖像授权的官方照片。
- 当前“事迹简介”是根据公开岗位信息生成的简要说明，并非逐人官方事迹全文。请在取得宣传部门审核的个人事迹材料后，改写 `brief` 字段为经审核版本。
